# Guardloop — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Model risk / validator

- As a model risk manager, I want continuous monitoring intervals for learning models, so that annual cycles are not my only defence.
- As a validator, I want fairness thresholds enforced at promote time, so that principles become controls.
- As a validator, I want alerts when non-causal local features dominate, so that carnival-as-permanent-risk failures surface early.

### Pricing / data science owner

- As a pricing owner, I want to see residual risk versus appetite before release, so that I am not flying blind into conduct risk.
- As a data scientist, I want sandbox runs visible to risk and compliance, so that challenge happens before production.
- As a pricing owner, I want a forced re-identify when expanding from internal to customer use, so that journey risks are not skipped.

### Conduct / compliance

- As a conduct officer, I want explainability packs for significant automated decisions, so that we can answer customers and regulators.
- As a compliance officer, I want fairness policy versions tied to model versions, so that accountability is traceable.

### Internal audit / board risk

- As internal audit, I want an export of Identify–Assess–Control–Monitor evidence for a period, so that assurance is evidence-based.
- As a board delegate, I want remediation status for AI risk breaches, so that oversight is actionable.

### HR / operating resilience (org-wide AI risk)

- As an operating resilience lead, I want visibility of manual fallback staffing for ai-critical processes, so that retirement of a model does not strand the firm.
- As a risk officer, I want organisation-wide AI culture risks logged beside use-case risks, so that talent and morale impacts are not invisible.
